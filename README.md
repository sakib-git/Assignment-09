- **Profile security** — Secured profile information
- **Secure account** — Login/Register safely with firebase authenticaiton

#### 🛠️ Technologies Used

- **React** — Single-page app architecture with modular components.
- **Firebase Auth & Firestore** — Secure login + cloud database.
